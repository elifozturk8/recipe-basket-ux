# Recipe Basket - AI-Driven UX/UI Grocery & Meal Planner

An interactive mobile and web application designed strictly around **Human-Computer Interaction (HCI) Principles**, balancing budget, time, and cognitive constraints for modern grocery shoppers.

---

## 📌 Project Overview & Value Proposition
In a world driven by fast-paced routines and high food inflation, **Recipe Basket** optimizes the user's patience, budget, and time. Instead of ordering costly takeout or sitting through long video tutorials, the platform utilizes AI to deliver concise, bite-sized cooking steps and automatically isolates missing kitchen ingredients to create a unified checkout experience. 

### Key Features:
*   **AI Smart Cart Integration:** Cross-checks recipe requirements against personal inventory to auto-populate only the missing elements into the basket.
*   **Dynamic Portion Scaling:** Adapts ingredient volumes fluidly based on real-time portion requirements.
*   **A/B Tested Dashboards:** Fully validated alternative layout architectures designed to minimize interaction friction and increase conversion metrics.

## 📊 Empirical Evaluation & User Testing (SUS Analytics)
The design ecosystem was evaluated through empirical user testing sessions involving 5 heterogeneous target users. System usability was tracked via standard **HCI Observation Sheets** and measured with the **System Usability Scale (SUS)**.

| **User 2 (Çağlanur K.)**| Student / High-Frequency Buyer | Promo Modal Handling -> AI Suggestions -> Rapid Checkout | **85.0 / 100** |
